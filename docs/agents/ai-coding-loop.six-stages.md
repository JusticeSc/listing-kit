## 总纲

**六环：选 → 说 → 切 → 验 → 因 → 学。**按任务选择必要环节；失败进入“因”，只回退受影响的环节，复用前提未变的实现与证据，不从头重复已完成工作。

**四项工作假设及其边界：**

1. **生成提速不免除验证责任**：需求、集成和验证仍可能成为瓶颈，但验证也能通过类型、工具和流程改进提效，不能由此推出“验证不可压缩”或要求每次全量检查。
2. **自动化可能削弱警觉**：不能靠主观顺畅感判断质量；检查应能暴露具体错误，但不能断言自动化必然降低人的能力。
3. **能力与任务、上下文及工具有关**：按当前模型和实际任务验证适用边界，不把架构、命名等类别永久列为AI禁区，也不把判断责任转交用户。
4. **边界与组合值得针对性验证**：根据实际风险检查异常、状态转换及跨模块组合；正常路径也可能有严重缺陷，不靠事故类比预先认定根因。

## 选：判断收益、风险与可验证性

同时考虑实现、理解、集成、验证和维护成本，以及错误后果与退路；验证便宜是有利条件，不是唯一准入标准。
交前明确：怎么算对、错了影响什么、改变是否可审查、失败如何恢复。
开发者主动承担架构、命名和跨模块分析，提出有依据的方案；仅将产品选择、缺失事实、权限或重大不可逆取舍交给用户。
做完标志：能说明为什么采用该方法、由什么证据验收，以及剩余风险。

## 说：明确可观察验收与边界

在现有Issue或本轮方法记录中，以“给定状态→动作→预期结果／不得改变的内容”固定真实行为和判错依据；适合自动化的使用实际入口，界面、人因和品质使用对应观察，不用用例数代签质量。
写清非目标与权限，自行查仓库约定、业务规则和相邻实现；多文件改变先确定消费者、验证与退路，只问影响行动且无法自行取得的信息。
做完标志：审查者不依赖实现也能判断该场景对错；Todo只指向下一动作。信息足够就推进，不为补齐表格或形式化文档延迟工作。

## 切：切到还读得动

改变切到能完整理解与审查的范围，不把固定行数当质量阈值；每片应是最小完整行为改变，必要消费者同组闭合，不交付空骨架或占位实现。
先保证可恢复；只有提交授权成立时，才按 `AGENTS.md` 的提交规则组织自包含commit。并行任务需有明确接口、文件所有权和集成责任，不要求逻辑上完全无关。
做完标志：每片结果、依赖、验证与退路清楚，不为缩小diff留下无法工作的中间产物。

## 验：分层检查，覆盖实际风险

1. **快反馈**——先按实际依赖选择范围，先跑最便宜且能判错的相关规则/合同检查，再按风险运行真实消费者smoke；前置失败明确记录后续未运行。机械检查只选受影响的编译、类型、lint或静态入口，不因“小改动”固定全跑，也不临时引入工具链；既定最终冻结准出另行满足。
2. **行为层**——通过实际消费者验证结果。AI可以写测试，但预期结果须来自需求、独立样例、业务不变量或可信基线，不能仅回声实现。需要时用受控故障或变异验证判错能力；只对确有风险的输入空间采用属性或模糊测试，不默认比有针对性的例子更有效。
3. **对抗与差异**——审查未测边界、异常吞噬和为刷绿削弱断言。测试删留按 `AGENTS.md` 的业务保护规则判断，不凭数量变化定罪或宣告改善；高风险时引入独立视角，但换人或换模型本身不保证判据独立。
4. **真实路径**——工程行为需实际smoke；界面验证真实表面。灰度或金丝雀仅在部署权限、环境和风险条件满足时使用，不能取代发布前验证，也不是每次任务的必经步骤。
做完标志：有与改变相符、能判错的实际证据，能说明验证范围与未证部分；工具成功仅证明其实际检查内容，不证明产品完整正确或未来不会失败。

## 因：保留失败，按假设定位

顺序：①保留原始失败，核对受测版本、输入、环境与检查本身，不能先假定是检查误报；
②有间歇性或竞态假设且重复安全时，设计有次数上限、观察项与停止条件的重复实验，保留全部结果；一次成功不抹去旧失败，少量重复也不能证明故障纯属偶然；
③按当前证据区分需求、实现、环境、检查或能力问题，一次改变一个可检验因素；不为凑固定分类反复重做；
④收费、有副作用或状态UNKNOWN的操作不默认重试，继续遵守相应授权与防重复规则；
⑤修后确认原失败条件下的目标行为恢复，分清根因修复与吞异常、删保护或跳测试带来的假绿。
做完标志：有可复核的原因与修后证据；若尚未定位，明确未决点和能区分假设的最小下一动作，不编造确定归因。

## 学：预测—核对—记录

对重复出现或高风险任务，只记录会改变下一次行动的结论，并落实到实际消费者；纠正项的三阶段与关闭条件按 `AGENTS.md` 软件工程执行纪律。复发先重开原纠正项，检查原因假设、措施强度和绕过路径，不再追加同一句提醒。
统计指标只在有真实记录、分母与适用范围时使用；无后续实际机会不声称长期效果，不为凑观察次数重跑。
做完标志：能指出实际改变及原失败条件下的效果证据；分析、写规则和保存记忆本身不是产品修复，也不强写无新信息的总结。

## 极简版

1. 选：权衡总成本、风险、退路与可验证性。
2. 说：明确目标、判错依据、非目标和权限。
3. 切：保持可审查、可恢复的最小完整改变。
4. 验：用独立判据分层验证实际结果。
5. 因：保留失败，按假设定位，重复实验有边界。
6. 学：把有证据的教训落实为可复用改变。

一句话：**主动承担工程判断，用实际证据验证结果；方法可以调整，事实、权限与验收底线不能为方便而放弃。**
方法若无法解释真实失败或改善决策，就修正方法，不强行把事实塞进六环。
