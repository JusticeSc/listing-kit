## 15. 详细施工批次与验证成本纪律

用户明确担忧“各种验证测试没有实际稳步推进开发进度”，要求仅做必要验证。以下把§14映射为**按可操作成果推进的施工顺序**，不是新增任务ID、另一份进度表或立即施工授权。正式任务/依赖仍在§6/§9；实际进度在state，各批的结果写入所承接既有任务的最少证据。历史done按原证明范围保留，施工前重新核对新缺口。

§15.2保留业务成果的原设计顺序，不是当前待重建清单；§15.6规定已实现版本的有限收口。恢复时先读取state，再按详细设计§11.5处理差距，不能从设置或原子联调组A重新开发。

### 15.1 开始条件与推进原则

- 首次正式启动只按§16.2做一次真实Goal/范围、受影响任务及代码/数据基线核对；真实绑定和前沿以state为准，不因每改一个文件重做启动审计。首次产品写入前必须取得实际数据恢复基线，方案或代码快照不代替运行证明。
- 顺序为**设置接线 → 人工事实/用途 → 默认生成 → 比较/返工/交付 → 图文辅助 → 最终集成**。先形成可控完整人工主链，之后图文理解只替换输入生产方式，不另建执行系统。
- 每批开始写清：用户要完成的动作、受影响消费者、不能破坏的边界、预计采用的最小验证及扩大条件。不是先写测试目录或长报告；改动连贯完成后再验。
- 一个批次交付的是可运行功能及其明确边界，不是页面空壳、只读设置框、未消费接口或假成功。批次成立不等于整个工程验收成立；剩余缺口如实保留。
- 采用已有domain/repository/执行Module和已批准协议，不重做存储/两生图Adapter、引入框架/Agent、重跑选型研究或购买重复证明。按§7.4在切片边界保存可回退基线，不为每次文本编辑另做一套备份和检查。

### 15.2 批次、具体改动与可见完成点

#### 设置接线：用户的配置真的进入请求

承接R4.3/R4.4/R6.3。先实现统一用途设置草稿/应用和当前页内存凭据；贯通**现有**文字理解、生图、单图/整套复核消费者，图文商品理解由后续批次补齐，不提前显示可用。

1. 正式Python装配解析受支持配置，给各用途注入请求级凭据；保留默认档closed、官方目标白名单、原任务目标和非秘密credential reference，不改进程全局配置。
2. workspace/index/settings投影同一解析结果；前端请求在对应动作上注入内存凭据，应用设置无外呼，缺key定位到该用途，百炼可共用引用，火山独立。
3. 参数变化影响新动作，旧已提交任务仍按原身份核对；刷新只丢秘密，不丢项目/候选，不自动改用部署key。

**完成点**：页面填key/选模型后，正式业务请求确实使用该配置；查看/应用设置不收费；原任务缺凭据能在原目标补给。只做一个设置框不算完成。

**主要位置**：workspace及设置投影、generation请求、product_v2_server、providers registry/credentials/outbound和现有semantic/review/suite_review消费者。

**最小证明**：同一离线正式入口，从页面应用配置并触发相关业务动作，在受控上游观察实际目标/能力/凭据使用（不写key原文）；核对未配key不外发、秘密不持久化/入包、新旧目标不串。复用现有消费者/安全判据，不重复两个协议的真付费链。

#### 人工事实与用途：不分析也能把方案做出来

承接R6.1的人工部分及R5.3相关依赖；以前一批共享配置为基础，不等待图文模型调用。人工批次可作为后续比较/交付的输入证据，但R6.1整项仍须后续图文辅助完成，不能先标done再让新消费者消失。

1. 空项目直接显示核心事实编辑入口，复用slots编辑/确认动作及来源/权限；人工明确保存确认不用跨页再确认，模型提议不越权。
2. 可以先建/编辑1..N任务草案，再补其所需事实/参考图；六个导航不锁区域，具体生成前置仍严守领域规则。
3. 用途需求集中suite-plan/specs：卖点/材质/成分/包装/对比有明确事实绑定；**实物尺寸数值/单位不同于输出像素尺寸**，有歧义只锁尺寸断言。

**完成点**：不配置理解/复核key、不分析，仍可确认商品、保存主图/场景/尺寸任务；缺尺寸只标尺寸待补，刷新后事实与任务真实保留。不是只在内部函数里证明人工可编辑。

**主要位置**：workspace/intake入口、domain slots/brief/suite-plan/specs及其repository消费者；不建立新字段库。

**最小证明**：一个页面任务，人工确认基础信息→建三种任务→补/留空尺寸→刷新；观察就绪/缺项、相应事实版本和保存后置。依赖/权限规则确有修改才执行其已有小范围行为用例，不跑全部网关/存储压力/生图回归。
