## 5. 表现层基线

**token（单一来源：`app/product_v2/styles.css` 的 `:root` 变量，组件不写死颜色/间距）**

- 颜色：中性底 `--bg` / 面板 `--surface` / 边界 `--border`；主色 `--accent`（一个品牌蓝，深浅两档）；
  语义 `--success` / `--warn` / `--danger` / `--info`；文本 `--text` / `--text-muted`；焦点 `--focus`。
- 字体：系统字体栈；字号 12 / 13 / 14 / 16 / 20 / 24；行高 1.4–1.6；字重 400 / 600；等宽仅用于 hash 与 id。
- 间距：4 的倍数（4 / 8 / 12 / 16 / 24 / 32）；圆角 6 / 10；边框 1px；阴影仅用于浮层，不用于普通卡片堆叠。
- 图片：缩略 64 / 96 可裁切，比较/审核图用 `object-fit: contain` 并保持原图比例；不得为统一卡片裁掉商品。预留图像区域避免结果加载后布局跳动。

**组件与状态**：按钮（primary / secondary / ghost / danger / link；default / hover / focus-visible / disabled / loading）、
输入与文本域（label / 帮助 / 错误 / 只读）、卡片（标题 + 说明 + 内容 + 动作区）、列表行（含徽标与行内动作）、
状态徽标（空白 / 进行中 / 成功 / 警告 / 失败 / 未知 / 过期）、步骤条、进度条、空态、错误条、
设置侧面板、就地比较/返工区、`<details>` 渐进披露区；采用不另开重复确认面板。

**无障碍与响应式**：正文与控件对比度 ≥ 4.5:1；移动端触控目标 ≥ 48px；所有输入有可见 label（不用 placeholder 代替）；
表单使用语义元素；`:focus-visible` 2px 可见轮廓；tab 顺序与视觉顺序一致；异步结果用 `role="status"`/`role="alert"`；
1440/1366 以图片比较为主区；125%/200% 实际浏览器缩放及390px改自适应布局、保留任务/候选身份和关键操作，不能用只缩 viewport 冒充 zoom。小宽度参考图可折叠，候选缩略及当前身份固定可找；不声称390px能达到桌面三图同屏比较效果。固定栏不得遮挡内容/焦点。

## 6. 代表状态清单（证据要求）

1. 空白/已有项目；2. 设置缺key/应用无外呼/关闭返回；3. 资料保存失败与人工入口；
4. 无AI分析仍可确认核心事实、先建任务；5. 按用途补尺寸/材质等，缺项只锁真实消费者；
6. 本地自动准备且无逐图编译门；7. 人工Prompt过期保护；8. 摘要变化后的发送拒绝；
9. 生成中比较成功图；10. 停止/继续未提交、明确失败、已知task/无taskUnknown与原key补给；
11. 旧/新/原图对照、单图返工和明确改选；12. 可选AI未运行/报告过期不误锁采用/导出；
13. 确定性硬门/风险及实际ZIP；14. 刷新/重开与配置变化；15. 默认/高级/诊断共享状态；
16. 1440/1366、实际125%/200%、390与键盘。完整代表任务及后置取计划 §14.9，不另建验收矩阵。

## 8. 走查、变更与生效

- **设计范围确认**：已确认业务选择取计划§13/§14，下一轮范围取§16。人工事实/采用、明确付费外发、可选AI、Unknown另发等权限含义是设计基线，正式触发后不擅改；普通布局可按局部原型/实际页面证据调整，不把每个像素冻结或每次重做全套基线。本次文本仍不是可点击原型/owner走查。
- **工程浏览器验证**：正式启动后从页面入口完成计划§14.9人工与图文辅助两条路径，含按用途补项、摘要生成、在途比较、局部返工/人改选、无AI交付、真实下载导入及刷新原任务恢复。页面/请求/IndexedDB/ZIP后置与截图实际读图共同证明；不得播种候选/调用内部函数绕过缺口，截图非空及fake不证明商品质量。
- **最终真人验收**：产品发起人走查/首次接触用户的C17/C15按计划§10/§16保持本轮之外、未发生，不由AI自审或工程自动化替代。工程Goal可按其适用条件验收，但不能把工程通过写成此草案已获真人签署。
- **生效与变更**：本文件转current仍需产品发起人实际走查确认，并同步INDEX身份/路由。设计范围确认不等于已走查，draft不阻止获准工程实现已确认业务合同；改变高风险含义需重新确认，普通表现调整记录原因/局部证据，任务状态只在state，完成只按计划。
