## 7. 证据、指标、验证与迁移通则

### 7.1 证据目录与证明范围

统一产物目录 `evals/product-v2/refactor/`；每报告首部 `NOT-AUTHORITY: point-in-time evidence`。文件名含任务ID、时点、代码/配置指纹及环境；原始日志/截图/录屏/包绑定报告。目录是任务输出约定，文件未生成前不算已有证据。

只有state或最终矩阵选中的最小集合成为长期证据；保持现有忽略/精确提升政策，禁止git add-A/整目录强纳入。提交前精确纳入必要新权威和证据，不能拿本地未跟踪报告证明CI可恢复。没有提交权限时报告“本地持久，未提交”，不偷提交。

### 7.2 UI测量与通过线

审计表记录每条路径的必要确认、非必要点击、滚动、跨区跳转、记忆项、误点、停顿和完成结果；相同资料/图数/窗口/角色比对。R2.2在修改前冻结具体目标：所有阻塞级问题必须有可执行修复/判据；高频比较和返工不得依赖记忆另一屏图片；错误有影响和下一动作；当前操作/图片上下文不被无关异步更新重置。不得事后改变指标解释或任意设“降低30%”；原型中某项操作增多需说明安全/理解收益并取得所需确认。

强制测量：桌面1440及1366，125/200%缩放，390px不遮挡关键操作/无非必要水平滚动；可读标签、当前状态非仅颜色、键盘焦点可见且不被固定元素完全遮挡；弹出层关闭后的焦点返回；保存/生成/核对有真反馈。常规文本对比≥4.5:1，适用大字/非文本规则另按WCAG分类，不把AAA当AA。高频目标建议44px及足够间隔，实际合同按现有48px基线/布局决定，不为密度任意缩小。

### 7.3 验证分层

- domain：直接JS行为、状态/边界/错误/失效，不依赖HTTP/Chromium；真实WebCrypto使用先核对宿主差异。
- 编排：真实Module Interface，捕获受控Adapter效果；单张/批量/返工共享消费者行为，不测mock回声。
- 网关：正式registry/config/credential/Adapter装配、协议请求/错误/secret隔离；fake只是替上游，不替产品路径。
- 浏览器：真实IndexedDB/事务、Blob、焦点、DOM、刷新/切项目/双标签、ZIP及console/network/存储后置。
- 供应商：预算内真请求证明能力、真实参考图、候选身份/费用；fake不能替代。
- 产品：C17/C15真实人审；self审/axe/截图不能替代。

删除源文本/注释/函数名/纯转发测试；保留能抓消费者可见错误的行为判据，不重钉新实现。验证入口以当前 `config/product-v2/verification.json` 和CI实际装配为准，区分离线/授权真实/人工/历史；新增入口必须有明确类别和消费者。现有 `verify_v2_2_3_intake_understanding.py` 已登记CI离线浏览器项，不能继续沿用“未接CI”的旧调查指令，也不能把登记本身当最终运行证明。

**必要验证纪律（用户本轮明确要求；执行细则见§15.3）**：不在每次编辑后运行验证，不把上述层次当作每批必须全跑的清单。先完成有用户可见成果的连贯批次，再按实际受影响消费者选择最小验证；有现成证据且对应代码/合同未受影响，不重复证明。默认不新增测试/探针/报告入口；必要新用例必须能抓具体消费者错误，不能是接线、命名、文案或mock回声。实际操作受影响路径的smoke不可省，但不等于跑整套浏览器回归；扩大范围必须说明传播风险及原检查为何不足。失败先定位/修复，再跑受影响项，不能反复重跑碰绿。

当前可执行控制命令（串行，路径均相对仓库）：

```text
uv run --locked python tools/check_docs.py --no-run
uv run --locked python tools/check_project_state.py
uv run --locked python evals/probes/docs_index.py
uv run --locked python evals/probes/project_state.py
uv run --locked python tools/refactor_resume.py
```

已批准前端命令从根 `package.json`/lock和验证登记读取，不重复维护另一份命令清单。获准本地观察时优先让产品服务器直接bind 0并读回实际地址，不恢复先探空闲端口再绑定的TOCTOU；无法读回端口的子进程另记限制。本次规划只运行必要文档/冷恢复检查，不启动产品或购买模型证明。
