### 12.2 已确认授权与执行限额

用户确认：完整工程成品＋自动化验收；准确第二型号及 GitHub Secrets 已配置；预算只有 5 元；公开许可真实商品图；现有栈自主推进；允许现有环境发布。此前建议的 100 元及自动选 Seedream 替代型号全部作废。

| 项目 | 本轮边界与实际使用规则 |
|---|---|
| 模型 | 现有 DashScope 与大陆火山引擎准确型号；官方协议、价格和数据条款在调用前核实，不重新开放选型、不以文档不明确为由偷偷替代 |
| 资金 | 全部新增付费合计 ≤5 元；按最大输出参数预留，已耗与未结算预留合计不能超上限；余额/赠送额度不扩大本授权 |
| 次数 | 代理自设更严执行上限：付费请求总计最多 12 次，其中生图最多 8 次、每次最多 1 张，语义/VLM 合计最多 4 次；与金额上限先到即停，不承诺用满 |
| 调用顺序 | 先免费完成装配与错误/边界验证，再在稳定版本做两模型必要真实参考图链；相同最终代码/配置的直接证据复用，不重复调用补报告 |
| Unknown | 有 task 按原身份核对；无 task 不重提；可能已计费的请求继续占用预留。确定失败也不启动通用自动重试 |

| 默认档 | 交付受限能力并验证拒绝/限制路径，生产默认付费档关闭；公开界面可使用 BYOK，不把部署许可解释为开放共享 key |

| 新依赖 | 现有已批准依赖内完成；无新框架或通用库授权，遇到缺口先复用或记录对应阻塞，不能把“自主”当无限依赖许可 |

### 12.5 验证、阻塞与交付纪律

- **本节为触发后有效纪律。** 启动观察证据同步前，不启动产品、供应商请求、Git 提交/推送或部署，不为交付计划新增验证代码或运行产品回归。
- 启动后切片只验证改变路径与关键不变量；完整回归集中于 R7.1 最终节点，已完成基线只在相关变更时复访。已有断言不足才增补可抓真实消费者错误的判据。
- 实际缩放须记录 viewport/DPR 与浏览器 zoom，键盘由页面级事件实现；无头限制不能冒充通过。保持 Chrome 无头/独立 profile/后台静默的操作范围。
- 运行时凭据注入、网络、官方型号/协议、准确价格上界或余额不可用：保留对应真实验收阻塞，继续全部离线实现与免费运行验证，不再索取用户重复确认，不暗换供应商或预算。
- 发布前必要验收失败时不把失败版本上线；修复后复核。发布动作失败时回退之前可运行版本，不拿本地检查替线上结果。
- 最终只选必要证据、记录限制和恢复点；README 描述实际实现，context 更新实际技术结论，state 表示真实完成/阻塞。不因写完计划、完成自动化或留好报告就标整个工程 Goal 完成。
