# 审核返工与交付
[返回 product-v2-ui-contract.md](product-v2-ui-contract.md)

### 4.7 阶段五：审核返工

| 层 | 内容 |
|---|---|
| 信息（默认） | 图片任务条及采用进度；当前同图工作区默认左商品依据＋右当前查看候选两图，按需历史对照时左对照位切为选定历史候选（商品依据可切回），不常驻空第三列；问题与采用状态紧邻图片。新交付以 design §13.3／计划 §17.13 为准 |
| 信息（展开） | 完整报告、当前候选原 Prompt/执行身份、历史；高级返工 Prompt |
| 行为 | 切换图片/候选、指定对照候选、等比例放大、局部返工、明确采用/改选、取消采用 |
| 状态 | 无候选、有问题、报告待运行/过期/未知、返工中、当前采用/尚未采用、旧候选、原任务待核对 |
| 规则 | 当前查看、对照、人工采用三者分开；候选切换不修改 Selection。未满足当前采用合同的历史候选可查看但说明不可采用原因，不暗改其身份 |
| 反馈 | “已采用：候选X”和“当前查看：候选Y”分别可辨；新图到达只提示可查看，不自动改选、换当前图或夺焦点 |
| 导航 | 从生成行带 shot/candidate 身份进入；切换任务与返回时保留位置。可在其他图生成时审核成功图 |

- 桌面主区横向直接对照，图片 `contain` 不裁商品，标明原图/候选与采用身份；缩略列表可裁但须能看原图。放大与共同尺度可选，不用截图差异替代肉眼比较。
- 返工区就地展开：选择问题/写方向 → 系统本地准备摘要 → “确认并返工这张图”。默认不要求先按“预览 Prompt”；高级全文可查可改，人工文本保护同生成区。
- 返工摘要明确目标图、作为依据的候选、参考图、模型、参数与新增费用；这次提交只影响该图，不改写其旧候选/旧采用，也不改变其他图记录。
- “采用当前候选”是明确的人工决定，直接保存并反馈，无第二个重复确认面板；改选显示将替换哪条采用。可通过历史再次改选或取消，不用导航代替采用。
- 确定性硬问题与VLM建议分别展示。AI复核可不做：不随生成、查看或采用自动调用，用户明确选择单图/整套后才外发并提示费用；未调用显示“未做AI复核”。采用/导出不因缺AI报告被锁，但确定性硬检查、人工采用及来源完整性仍强制。详细政策取计划 §14.8，不造空报告/PASS绕旧门。

| 操作 | 前置与结果 | 恢复/反馈 |
|---|---|---|
| 切换任务/候选、指定对照、放大 | 只改变查看上下文，无提交/采用 | 保留当前图位置；缺字节提示真实恢复条件 |
| 采用当前候选（主） | 候选符合既有采用合同；保存 Selection | 成功显示精确候选；失败保留原采用；不能先给成功反馈 |
| 取消采用（次） | 明确撤销该图选择，不删候选 | 显示未采用；可再次选历史候选 |
| 确认并返工这张图（返工区主） | 目标及方向有效，摘要当前 | 先冻结登记再外发；失败/Unknown规则同生成；旧图保留 |
| 复核当前查看候选 / 复核当前采用套图（次） | 能力/key就绪，明确具体候选或采用集合及发送内容/费用 | 冻结该身份/快照，报告不偷取最新候选；操作期间切图/改选，返回只能属于原对象，不贴给新选择 |
| 查看交付条件（导航） | 始终可打开；硬门仍约束导出 | 精确定位缺采用/字节/确定性检查，不以缺AI复核要求购买调用，也不加重复采用确认 |

```text
审核与返工                     已采用 n/N · 后台 m 张生成中
图片任务：[主图] [场景图] [细节图] …（状态文字）
-----------------------------------------------------------------
左对照（默认商品依据；按需切历史候选） | 当前查看：新图B
     保留原图比例  | 状态/问题紧邻图
-----------------------------------------------------------------
候选缩略历史           已采用：A   当前查看：B
[采用当前候选 B]       [返工这张图]     > 来源/完整报告
返工区（按需）：问题 + 改进方向 + 本次发送摘要
[确认并返工这张图]     [收起，不提交]    > 完整 Prompt
```
(本草案仍为 draft；当前入口与新交付以 design §13.3／计划 §17.13 为准。)

### 4.8 阶段六：交付

| 层 | 内容 |
|---|---|
| 信息（默认） | 已选候选/来源；硬阻断与仍存在风险分列；单图/整套AI状态明确未运行/当前/过期 |
| 信息（展开） | manifest预览：采用原图/动作/规格版本、确定性实际检查、AI状态与风险知悉；导出历史 |
| 行为 | 就地修复具体硬阻断、导出完整项目包、生成采用成果的交付包；复核是可选入口 |
| 状态 | 硬阻断、硬门通过但有风险、生成中、已生成、失败；未做AI复核本身不是硬阻断 |
| 规则 | 门禁取计划 §14.8及domain；缺选择/字节/hash/确定性硬失败阻断，不把VLMUnknown或无AI报告变成BLOCK；无关未采用Unknown不一律锁项目；原动作链及追加式导出保持 |
| 反馈 | 阻断项可点击直达修复位置；导出失败给分类原因并可重试 |
| 导航 | 返回审核/生成修复阻断；导出完成显示结果与复检入口 |

**按钮清单**

| 按钮 | 为什么需要 | 前置 | 结果 | 失败反馈 |
|---|---|---|---|---|
| 定位到阻断项（行内） | 阻断必须可修复 | 存在阻断 | 跳到对应图片/阶段 | —— |
| 导出完整项目包（次） | 全部项目对象/历史与素材备份；可用于换浏览器恢复 | 项目存在且满足既有包合同 | 浏览器生成项目 ZIP，无秘密 | 失败给分类原因，导入后需要重新提供凭据 |
| 生成交付包（主） | 最终采用成果 | 既有硬门通过；风险仍单独提示 | 浏览器生成交付 ZIP，manifest 源于采用候选原动作 | 精确定位未通过项，不读取当前编辑 Prompt 冒充历史来源 |
