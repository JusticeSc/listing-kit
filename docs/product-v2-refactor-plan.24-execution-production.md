#### 默认生成：摘要后一次发送，技术步骤由系统承担

承接R5.1/R5.3/R6.1；消费前两批已保存输入。

1. 按真正消费的事实/规格/参考图/能力投影Basis，自动准备缺失/过期系统Prompt；相同依据复用版本。
2. 人工Prompt保留原文/草稿及过期原因，明确复核或放弃后重编；发送摘要来自将实际发出的文本/参数。
3. 一次确认绑定明确的新提交集合；提交前再验指纹，先冻结登记再外发。成功/在途/Unknown不混入“重新生成”；停止/继续沿用原集合/身份。
4. 单张/批量/局部返工共享执行，不复制状态机或加供应商业务分支；保留已成功候选和原动作链。

**完成点**：默认用户无需逐图编译或先确认再找另一个生成按钮；主图/场景可发送，缺项图定位明确；人工文本不被自动覆盖，变化后的旧确认不能外发新内容。

**主要位置**：domain prompt/confirm/invalidation，generation及workspace逐图摘要/进度。

**最小证明**：正式页面用本地fake外部响应完成一批；包含正常生成、一次人工文本过期及一次发送前依据变化。执行状态机确有改动再加partial/停止/Unknown对应已有判据；只换文案不重复这些状态机检查。fake不证明真图质量，不购买新调用。

#### 比较、返工与交付：先完成可控人工主链

承接R6.2/R6.3，消费前序人工输入及生成能力，复用既有candidate/selection/review/ZIP。R6.2正式依赖R5.3，不等待R6.1图文部分；R6.3本批只交付人工主链，全用途/图文及最终验收仍须闭合才可整项done。

1. 同shot显示参考/旧/新候选，查看/对照/采用分开；成功结果可提前比较，后台到达不切图/抢焦点。
2. 就地返工生成新候选，保留旧采用；无关shot的记录/hash/选择不变；人工改选/取消是明确动作。
3. 单图/整套AI复核只在主动发起时调用，冻结所点候选/当前采用集合，不偷取最新图；未运行AI单独记not_run，不造模型Unknown或假PASS。
4. 保留当前确定性报告、硬检查、真实字节/hash和来源链门；AI可不做。交付ZIP取采用原动作，项目ZIP保留历史且无秘密，错误可就地恢复。

**完成点**：从人工输入一路到实际交付包，不做AI理解/复核也能完成；局部返工能改选旧/新图，实际导出与所选字节一致。不是候选列表和“导出成功”提示就算交付。

**主要位置**：workspace比较/返工/交付，domain compare/rework/selection/review/suite-review/export-gate及storage package/transfer。

**最小证明**：复用上一批项目和候选，在同一页面比较→返工→改选→无AI导出→实际下载/导入。核对目标/无关shot、ZIP字节/hash及未AI标记；额外选一条真实硬失败验证仍阻断。仅在改动ZIP/事务实现时扩大到对应存储/包边界，不例行重跑存储压力测试。

#### 图文辅助：真正看图，但不接管事实权限

承接R4.3/R6.1，补齐设置批次中尚未实现的商品图文消费者；以可用人工主链为基底。

1. 演进商品理解请求/提案合同，显式文字/图文模式及有限模型能力，复用qwen-vl传输，不复用candidate审核输出词表。
2. 实际读取所选原图字节，严格校验类型/hash/有界输入，给出原资料身份、图像发送事实、提议/证据/问题；文字路径明确没看图。
3. 处理与原确认值的冲突及迟到结果，只归属原资料快照；人确认后进入同一事实/方案/编译路径，不另建模型专属项目状态或自动生成链。

**完成点**：用户明确发起后，正式上游消息带图片；提议可核对来源并由人确认；缺key/模型失败仍可继续人工任务。离线接线成立与真实视觉提议有效分别记录，未获准真调用不能声称后者通过。

**主要位置**：semantic业务合同/Adapter、现有langchain_chat多模态传输、registry/正式HTTP装配、workspace资料/提议消费。

**最小证明**：受控正式上游捕获图像/资料身份，合法提议及冲突/越权输出经过页面确认/拒绝，晚返回不覆写新资料。正式启动后至少一次真实图文理解输入/合法提议证据；若修改复核能力再补其必要证据，共用§16.1额度。无授权、费用上界或环境条件时只阻塞真实动作，不用fake代替，也不随离线回归重复付费。

#### 最终集成：收口而不是再建验证项目

承接R7.1/R7.4，前提是上述缺口实际关闭，G6成立；不能因规划写完推进。

- 在最终候选版本覆盖§14.9完整任务、实际视口/缩放/键盘与正式入口；同一动作轨迹同时提供请求/IDB/ZIP和视觉证明，避免按“页面”“存储”“接口”分别重复同一全链。
- 现有R7.1两轮离线完整回归仍是既定最终门，**只放在最终收口，不逐批跑**；不重复真实付费链。不是用连续绿色证明间歇失败根治，不掩盖原失败。
- 按§15.3逐路径判定历史真实证据是否仍适用；两生图协议/上游能力未改不重复付费。生图次数已满，旧证据因必要变更失效则对应验收保持未证并请求专项授权；新增图文/复核只用§16.1批准额度，不为调试/报告消费。
- 发布前按§7.6闭合缺陷、按§7.4/§7.7准备服务/数据回退；CI/审查/保护满足后按§16.1获批方式合并并验证现有环境。C15/C17、V1日落仍在本轮之外，不冒充完成。
