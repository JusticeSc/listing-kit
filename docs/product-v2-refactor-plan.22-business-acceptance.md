### 14.9 代表任务与人因验收

以下是设计/工程的同一场景，预期后置不是本轮已执行证据。用同一商品资料、真正页面入口、实际输出对象/字节做对照；不通过直接播种候选或调用内部函数绕过操作。人因判据是识别/记忆/决策/定位/恢复负担，不预设无基线的“降低百分比”。

| 场景 | 人的任务与系统应承担的工作 | 必须观察的业务后置 |
|---|---|---|
| 纯人工完成 | 参考图＋名称/品类/保留特征，选择主图/场景/尺寸三任务；不配置理解或复核key、不分析 | 手动确认可达；无尺寸只锁尺寸任务；主图/场景可本地准备并在生图key就绪后明确发送，采用后可不做AI复核导出所选就绪任务；调整导出范围必须显式变更套图，不静默漏图 |
| 同商品图文辅助 | 明确发送原图/文字，处理材质猜测、尺寸未知和与原确认值冲突 | 真正发出图像字节；提议/证据可查，只需处理实际相关字段；人确认后与人工路径形成相同消费合同，不存在模型专属导出捷径 |
| 按用途补信息 | 增加有依据的卖点或包装任务，后补尺寸数值/单位 | 只出现选用途所需字段；一次确认共用事实解除对应缺项；尺寸准备不使主图候选失效，未经确认声明不进入Prompt |
| 默认与高级控制 | 普通用户看摘要一次提交；高级用户改某图完整Prompt，再改其消费事实 | 默认不逐图编译/逐页重复确认；系统文本自动准备、人工文本保留且过期原因明确；摘要实际变化时拒绝沿用旧授权发送 |
| 并发比较与局部返工 | A成功、B在途、C结果未知时查看A，对照参考/旧/新图并返工A | 不靠记忆另一屏；B/C及A原采用/原候选不变，新结果不跳图/抢焦点；只有人改选才改变Selection；C不自动重提 |
| 停止、刷新、换设置 | 停止新增，换生图配置/清key，刷新后恢复原已知任务和旧队列 | 状态保存真实；提示原目标补key，核对零新submit；原身份恢复未提交集合；无task另发明确重复扣费风险 |
| 可选AI复核 | 先不运行并交付；再主动复核某图/整套，过程中改选 | 不运行无AI外呼且manifest记not_run；运行才有费用动作，改选后的旧报告不贴到新选择，不强制补调用；确定性门一直存在 |
| 完整交付与重开 | 查看硬阻断/风险，导出两类ZIP，实际下载并在隔离项目导入，检查刷新 | 导出集合/原字节/hash/来源一致，无secret；项目包保留历史；缺采用/字节失败能就地修复，恢复不重新生成或伪造当前报告 |

界面认知走查还应覆盖：下一步及“为何不可操作”可辨；术语以图片目的/事实/候选为主，技术身份渐进披露；同图上下文及修改范围可见；默认/高级/诊断不改变业务真相；1440/1366、实际125%/200%及390关键操作可达、键盘焦点可见。真实页面、请求/IDB/ZIP后置与视觉共同证明；测试数量不代替完整任务。

### 14.10 既有任务与消费者承接

| 既有任务 | 必须对齐的消费位置/缺口 | 证明边界 |
|---|---|---|
| R4.3 / R4.4 | provider配置/registry/credentials、正式设置和现有文字/生图/单图/整套复核消费者、原动作身份 | 基础配置先闭合现有消费者；新增图文消费者由R6.1复用同边界，最终RC07仍全用途；原task只用原身份 |
| R5.3 / R6.1 | intake/slots/brief、suite-plan/specs、prompt/confirm/invalidation/workspace及新增semantic图文合同/正式消费者 | 人工先可用、图文后接同事实合同，按用途依赖/本地摘要共同成立；字段规则不复制到UI/网关，图文提议不借审核schema |
| R5.1 / R6.2 | generation及attempt/batch/rework/candidate/compare/selection/review | 共享执行、partial/Unknown与局部隔离、直接比较、人采用、AI不自动调用且不强制采用 |
| R6.3 | review/suite-review/export-gate、manifest/transfer/package及UI设置/交付/恢复 | 保留当前确定性报告门，迁移not_run→模型Unknown/强制补调用及不真实checks内容；真实ZIP/原动作链/secret隔离保持 |
| R7.1 / R7.4 | 按既有门消费已完成切片的完整任务与运行证据 | 旧矩阵/旧发布不覆盖新合同；先补真实缺口，不加并行任务表或重复付费证明 |

以上是承接责任，不声明新合同已实现。需求修订后的任务完成语义按§7.5，下一轮启动按§16.2一次核对受影响任务/依赖/Gate，不用旧done跳过新增验收，也不重做未受影响成果。实际进度/权限缺口/证据只在state；UI仍draft，纸面和恢复一致性不证明页面、真实模型、图片质量或C15/C17。
