实测（本机，uv pip install --dry-run，2026-09-30）
- 候选 A 官方 SDK dashscope==1.27.7：解析并安装 32 个包，额外拖入 aiohttp、attrs、
  websocket-client、typer + shellingham、yarl、aiohappyeyeballs、annotated-doc 等。
- 候选 B 复用 requests（已是直接依赖）：新增 0 个包；需要自己写 DashScope 异步提交 /
  任务轮询 / 结果下载与错误映射。
- 候选 C httpx 或 openai SDK 兼容端点：百炼图像合成不是 OpenAI 兼容图像接口，
  httpx 只多出第二套 HTTP 客户端而没有协议收益，不作为候选。

仓库内既有实现（可迁移，不属重复造轮子）

  request_id 校验、错误码提取、result URL 白名单、模型与尺寸校验。
  V2.7.5 会删除 V1 链路，但协议知识在这一批迁到 V2 网关即可复用，不必为此引入 32 个包。

推荐（等用户点头后才写进 §4.1）
