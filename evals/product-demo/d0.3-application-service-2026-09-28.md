# D0.3 Application Service 实现与验收（2026-09-28）

**结论：D0.3 通过，允许进入 D0.4 S0/S1 前端。** 本结论只覆盖正式服务层的工作空间/商品资料合同；尚未接入 HTTP 路由或页面，不代表本产品已可由使用者操作。

## 交付

- `src/application_service.py`：框架无关的 `create_workspace`、`open_workspace`、`get_workspace_projection`、`save_intake` 服务接口；读取和写入均以 WorkspaceStore 为唯一业务权威。
- `tools/verify_application_service.py`：7 项离线 API/服务合同测试。
- `docs/product-demo-goal-and-implementation-plan.md` §9.1：记录响应 envelope、错误字段、UI 投影和资料保存边界。

## 验收证据

| 场景 | 结果 | 证明内容 |
|---|---:|---|
| 空白创建 | 通过 | 创建 `NEW` 工作空间；投影只含 Workspace、Intake、Readiness，无 Plan/生成/候选占位 |
| 缺少名称或参考图 | 通过 | 返回定位字段、缺项列表和下一步；索引与输入目录均不变化 |
| 错误工作目录 | 通过 | 文件路径与不存在的父目录得到稳定错误；不覆盖哨兵文件或创建半成品目录 |
| 无效参考图 | 通过 | 解码失败在写入前返回；不产生原图或 ProductInput |
| 保存与关闭后重开 | 通过 | PNG 原始字节/hash、用户输入、平台版本和引用关系恢复；修改形成 v2，v1 文件保持不变 |
| 重复保存与并发冲突 | 通过 | 相同内容不增加版本；陈旧 ETag 先拒绝，未留下孤儿图片或记录 |
| 稳定响应结构 | 通过 | 成功与失败都使用固定 `{ok,data,error}`；失败 `error` 字段集合固定 |
