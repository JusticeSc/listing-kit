## 8. Mock 边界与演示控制

模拟什么：模型执行、等待时间、费用、写盘。
不模拟什么：商品理解、方案推荐、提示词编译、返工影响——这四项由同一份通用编译器按输入推导；Aster 01 与 Bex 02 得到的理解、张数、用途与提示词互不相同，就是这项的可见证据。

演示控制条放在产品界面之外的独立深色条（页面顶部），只提供：情形注入（正常 / 局部失败 / 结果未知）与复位。业务界面内不出现场景开关、重置按钮或测试入口。

夹具声明：

| 夹具 | 覆盖范围 | 说明 |
|---|---|---|
| Aster 01 保温杯 | 完整轨迹：资料 → 理解 → 方案（3 张）→ 生成 → 审核 → 返工 → 交付 | 候选来自首轮真实产物（F-01…F-04）与参考包产物；一个细节张使用标注过的 UI 夹具 |
| Bex 02 方形随行瓶 | 因果对照：理解、方案（2 张）、提示词差异 + 主图候选 | 主图候选为 UI 夹具（合成图）；其余张明示「无演示候选」 |
| 其他任何输入 | 只做输入校验 | 不套用任何已有商品的事实与候选 |

候选真实性标注（候选元数据行可查）：首轮真实产物 / UI 夹具 / 模拟返工候选（Phase 2 不调用模型）。


## 9. 与上一版（v1.21 / D2.R1d–e）的差异

| 维度 | 上一版 | 本版 |
|---|---|---|
| 布局 | 固定三栏，未来阶段以空态占位 | 阶段式单主视图；已完成阶段折叠成一行摘要 |
| 运营负担 | 每张图渲染完整 F1–F8，全部通过才可选 | 无异常只给一行摘要；检查详情退到高级区 |
| 方案来源 | 固定 Shot 定义（4 张） | 类目 playbook + 商品资料编译（Aster 3 张 / Bex 2 张） |
| 提示词 | 商品常量；输入不驱动输出 | 5 块编译；可查看、可编辑、可恢复推荐、有版本 |
| 失败与情形 | 演示开关放在业务界面里 | 情形注入放在页面之外的演示条；业务界面只有业务 |
| 导出 | 直接给文件列表 | 清单预览并明确「未写文件」 |
| 商品边界 | 非示例商品也套示例结果 | 未支持输入明示「无演示候选」并停止 |

## 10. 反向探针（设计侧，评审时可逐条核对）

| 探针 | 故意注入的变异 | 期望 |
|---|---|---|
| 固定张数 | 让 Bex 02 得到与 Aster 相同的张数与用途 | 跑红 |
| 常驻三栏 | 任一阶段同时渲染候选区与交付区 | 跑红 |
| 常驻检查表 | 审核页出现 F1–F8 八行表 | 跑红 |
| 商品泄漏 | Bex 02 的提示词里出现保温杯/青绿/筋条字样 | 跑红 |
| 无因果 | 改卖点后提示词与「需更新」标记不变 | 跑红 |
| 假成功 | 未全部采用仍可导出，或把清单预览说成已写文件 | 跑红 |
| 假百分比 | 「生成中」出现百分比进度 | 跑红 |
| 颜色唯一编码 | 去掉徽标文字后无法分辨状态 | 跑红 |

## 11. 待产品发起人确认（≤5 问）

1. 张数由类目 playbook 决定（示例 3 张 / 2 张）是否符合你对「一件商品一套图」的预期？
2. 审核页三区（缩略条 / 大图 / 操作区）是否合适，还是要更简？
3. 返工原因的 6 项封闭集是否覆盖真实退回原因，缺哪一项？
4. 提示词放在审核页高级区（可查看、可编辑、显示版本）是否够，还是方案页就要能直接改？
5. 演示导出的清单字段（文件名、用途、候选版本、提示词版本、平台规格）是否够用？

## 附录 A 走查脚本（产品发起人，8 步）

1. 打开原型：空白表单上是空的；主按钮禁用并写明还差什么。
2. 点「加载示例商品 → Aster 01 保温杯」；检查 3 张参考图与角色、3 条卖点；点「分析商品资料」。
3. 在「商品理解」里点「修正理解」，把一条卖点改掉；保存后确认，进入方案。
4. 在方案页展开任意一张的「默认提示词」，确认 5 个块与负向提示词都在；改一次「全组视觉」；点「一键生成套图」。
5. 生成页：等三格走完；把演示条切到「局部失败」重跑一次，看失败张与重试；再切「结果未知」看查证路径。
6. 审核页：切候选、并排比较；对第 2 张点「重做这张」，选一个原因，观察只有这张变、旧候选保留。
7. 全部「采用这张」后进交付页；点「导出套图」，确认得到的是清单预览（明确未写文件）。
8. 换「Bex 02 方形随行瓶」重走前四步，对比理解、张数与提示词的不同。

| 验证项 | 新鲜读数 | 能证明 | 不能证明 |
|---|---|---|---|
| 空白态 | 主按钮禁用，检查行点名缺什么 | 资料门禁按输入生效 | 真实用户的填写习惯 |
| 示例载入 | 3 张参考图（首图 1344×1344 真实加载）+ 3 条卖点 | 示例进入同一张表单，不另开路径 | 非示例商品的真实理解 |
| 方案 | Aster 3 张、Bex 2 张，用途不同 | 张数与用途由类目数据决定，不是固定 4/7 张 | 品类覆盖度 |
| 提示词 | 7 个部分；含事实锁、全组视觉段；Bex 提示词无保温杯泄漏 | 提示词由输入编译 | 真实模型成像效果 |
| 生成 | 3/3 就绪；局部失败可单独重试；结果未知必须先查证再重试 | 失败/未知不污染其他张 | 真实服务行为与计费 |
| 审核与返工 | 候选可切换、可并排比较；返工后候选 2→3 且只有该张变化 | 单图返工语义与旧候选保留 | 真实新图质量 |
| 因果 | 改提示词 → 仅该张需更新（stale=1）；改全组视觉 → 3 张待更新；单张更新后 stale=2 | 失效传播按声明范围生效 | 跨进程持久化 |
| 交付 | 未全选时导出禁用；全选后导出为清单预览（明确未写文件） | 门禁与诚实边界 | 真实文件写出与命名规则 |
| 布局 | 1440 / 720 / 390 宽均无横向溢出；控制台错误 0 | 响应式与交互稳定性 | 真机与浏览器 200% 缩放（720 宽为近似） |
