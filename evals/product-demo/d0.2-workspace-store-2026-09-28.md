# D0.2 WorkspaceStore 实现与验收（2026-09-28）

**结论：D0.2 通过，允许进入 D0.3 Application Service。** 本结论只覆盖文件夹工作空间的持久化组件，不代表 D0.3—D4 已完成，也不代表产品可以对外使用。

## 交付

- `src/workspace_store.py`：空工作空间创建/打开、跨线程与跨进程锁、ETag 比较写入、内容 hash、不可变文件/记录与版本分配、引用校验、索引原子替换。
- `tools/verify_workspace_store.py`：8 项离线核心验收。
- `tools/verify_workspace_store_concurrency.py`：2 项线程/进程互斥验收。

## 验收证据

使用项目锁定依赖和 Python 3.13，在本机临时目录运行；测试不读取或改写任何真实商品工作空间，也不联网。

| 验收面 | 结果 | 证据范围 |
|---|---:|---|
| 创建、重开、拒绝在非空目录上初始化 | 通过 | 空白索引可读；非空目录哨兵文件原样保留 |
| 素材与版本记录不可覆盖、版本递增 | 通过 | 同一 ProductInput 形成 v1/v2；旧文件字节不变，素材重复写入不同字节被拒绝 |
| 提交前异常/进程崩溃 | 通过 | 替换失败与子进程在 `os.replace` 前退出均保留旧索引；完整临时文件留在原处供诊断 |
| 提交后进程崩溃与恢复 | 通过 | 子进程在索引替换后、目录同步前退出；重开读到新指针，临时文件已被替换移走 |
| 陈旧 ETag 与悬空当前指针 | 通过 | 旧快照不能覆盖新索引；引用不存在版本的索引被拒绝打开 |
| 线程锁与进程锁 | 通过 | 竞争者在持锁期间按有限超时返回 busy；释放后工作空间可再次进入 |
| Product V1 契约回归 | 通过 | 30 个已有合同正反例全过 |
| 项目状态守卫 | 通过 | J0–J10 全过（在本报告写入及状态更新后重跑） |

核心验收 8/8、锁验收 2/2；语法检查通过。执行命令：

```powershell
uv run --no-project --with-requirements requirements.txt --python 3.13 python -m py_compile src/workspace_store.py tools/verify_workspace_store.py tools/verify_workspace_store_concurrency.py
uv run --no-project --with-requirements requirements.txt --python 3.13 python tools/verify_workspace_store.py -v
uv run --no-project --with-requirements requirements.txt --python 3.13 python tools/verify_workspace_store_concurrency.py -v
uv run --no-project --with-requirements requirements.txt --python 3.13 python tools/verify_product_v1_contracts.py
uv run --no-project --with-requirements requirements.txt --python 3.13 python tools/check_project_state.py --project .
```

核心验收明确覆盖索引替换前/后的独立子进程强制退出，不是硬件断电或文件系统损坏测试。当前 Windows 实现不做目录 `fsync`；本验收证明进程异常终止后的可读恢复，不证明突然断电时的介质持久性。

## 当前边界与下一步

Store 仍未接入正式 Application Service 或用户界面。D0.3 需定义服务输入/输出、错误结构及工作空间投影，并证明服务只通过 WorkspaceStore 读写，不把旧 Mock 内存态作为权威。真实模型请求、候选生成、首次使用者走查仍在后续 Gate，不能由本报告替代。
