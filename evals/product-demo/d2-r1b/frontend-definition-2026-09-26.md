## 3. 本轮发现并修正的设计错误

v1.17 预先限制“必要按钮只有七个”，却同时要求用户可手动调整系统默认方案。两者不能同时成立。
本轮改为动作驱动：添加 Shot、移除可选 Shot、排序和内联修改都是 Plan 草案能力；`一键生成套图`
同时固化用户眼前的 PlanVersion，不再额外增加“确认方案”步骤。

返工也不再只有“重做”：商品身份错误不能靠堆提示词解决；技术规格和精确文案不应再次付费生图；
Unknown 未核对前禁止重复提交。这个路由已经进入计划 §4.7.6 和视觉稿右侧返工区。

## 4. 仍缺的验收

FE-01–FE-04 的候选产物已经落盘，但 D2.R1b 任务要求产品发起人确认。当前尚无对本轮视觉稿的实际
走查记录，因此 state 保持 `D2.R1b: active`，不标 done。需要产品发起人打开视觉稿，至少切换
状态 1、3、5、7、8、9，确认以下四件事：

1. 输入来源、默认增强和演示范围没有伪装成通用商品能力；
2. 一键生成的是当前整套方案，不需要逐张启动；
3. Prompt 修改、商品核对、候选选择和按原因单图返工的关系符合预期；
4. 页面除必要资料、候选、检查和动作外没有冗余区域。

确认后才能把 D2.R1b 标为 done 并进入 D2.R1c；视觉稿本身不证明前端已经可用。
