价格说明​
视频价格由 token 单价 和 token 用量 共同决定。一般来说同等条件下：​
高分辨率的单条视频价格 > 低分辨率​
含输入视频的单条视频价格 > 不含输入视频​
每条视频的价格可使用 Seedance 2.0 系列价格计算器 、Seedance 2.5 系列价格计算器 估算，也可参考下方 价格示例 了解典型场景的视频价格。​

视频价格估算公式：token 单价 × token 用量​
token 用量估算公式：(输入视频时长+输出视频时长) × 输出视频的宽 × 输出视频的高 × 输出视频的帧率/1024，该计算结果为估算值，准确 token 用量以调用 API 后返回的 usage.completion_tokens 字段为准。​
Seedance 2.5 样片（Draft）模式 包含两步任务，每个任务独立计费：​
Step 1：生成 Draft 视频，按 480p 视频计费。​
Step 2：基于 Draft 生成正式视频，按目标分辨率计费：​
token 单价根据 Step 1 是否包含输入视频确定。​
计算 token 用量时，输入视频时长按 Step 1 的输入视频计算，Draft 视频不计入。​
价格示例​
基于 token 用量公式估算的视频单价，方便您直观了解不同规格的视频成本。更多价格示例请参见 火山方舟视频生成模型价格快查表。​
最低 token 用量限制说明​
对于 Seedance 2.0 系列、Seedance 2.5 模型，当输入包含视频时，存在最低 token 用量限制：​
如果估算 token 用量 ＜ 最低 token 用量，则按最低 token 用量计算视频价格。​
最低 token 用量与分辨率、宽高比、视频输出时长有关，可查询 Seedance 2.0 系列最低 token 用量表格（估算值） 、Seedance 2.5 最低 token 用量表格（估算值） 或使用 Seedance 2.0 系列价格计算器 、Seedance 2.5 系列价格计算器 估算视频任务的最低 token 用量，准确用量以调用 API 后返回的 usage.completion_tokens 字段为准。​
