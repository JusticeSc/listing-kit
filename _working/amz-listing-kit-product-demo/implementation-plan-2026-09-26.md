执行细节记录，非权威
本文件只展开怎么做与做到什么算完，不新增目标与门。目标合同任务图唯一权威为产品演示目标与实施计划 v1.14。进度证据唯一权威为产品演示执行状态。下文任务代号均为对权威计划的外键。
一 现状基线
阶段负一零一已关，二在做。D2.R1离线 tracer 已有，R2.a 说明观察表落点判据齐，失败路径七项按记录为绿，R2.b 缺真实未参与者，门二未过。首轮四张已结算，模式为 image to image，模型三点零，同一提示词哈希同一参考图哈希，还剩一次单变量复验额度四张。正式生成唯一入口为图生图适配器，旧文本直发与空背景加贴图已无使用资格，离线三动作明确标假，不计入完成证据。
二 横贯门
预算门 首轮四张加一次单变量复验累计不超过八张，超限直接拒，复验须写清单一变量。
未知门 超时与外部不确定记未知，核对原任务后决定是否重试，不自动重试。
废除门 正式生成只接受图生图，纯文生图本地贴图与占位图不得计入事实审美预算与完成证据。
版本门 展示文本等于发送文本，改一次产生新提示词版本并绑定候选，硬事实删除触发阻断。
隔离门 返工只动目标图，未动图候选选择哈希不变且新增提交为零。
三 任务展开
T0 控制面纪律
目标 散落文件不再增，权威唯一。
输入 权威计划与执行状态。
处理 新增只追加证据，计划只升版修订条，进度只改状态文件，旧备份脚本归档。
产出 本文件与后续走查协议。
验收 文档守卫与状态检查全绿，无第二个任务图。
失败 出现第二个出处即停，先归档再开工。
T1 D2.R2b 真人走查，依赖 D2.R1
目标 一名真实未参与者走通离线任务。
输入 九份齐全商品包，去开发者词汇说明，无路径编号界面。
处理 真人看页完成默认方案确认提示词改版候选比较单图返工选择与导出预览，开发者只观察。
产出 观察记录与语言缺陷清单。
验收 介入为零，疑问误操作培训需求齐备。
证据 说明观察表与过程记录。
失败 找不到人则门不过，不拿自测与代理顶。
T2 D2.R3 冻结边界，依赖 T1
目标 关掉三到五阶段入口拟定项。
输入 走查记录。
处理 只保留被真实需要证明的对象页面与接管点，写清删除项与理由，修订用户可见边界。
产出 最小清单与合同修订。
验收 每个保留项指向走查需要，五步只算候选。
失败 走查推翻流程先改原型合同，不迁就后端设想。
T3 D3.R1 领域状态合同，依赖 T2
目标 定最小对象与转换。
输入 冻结清单。
处理 只纳入观察需要的对象，写清身份边界与迁移线，界面暂态不入库。
产出 模型与正反例。
验收 身份边界可判定。
失败 未观察需求不预建。
T4 D3.R2 持久化与不可覆盖文件，依赖 T3
目标 状态可恢复，文件不覆盖。
输入 T3合同。
处理 建库迁移与文件登记备份恢复。
产出 可恢复实现。
验收 全对象可恢复，原文件不动。
失败 不建全量事件溯源。
T5 D3.R3 默认计划与完整提示词，依赖 T4
目标 免写提示词即可开始。
输入 事实卡参考包与风格约束。
处理 编译计划版本与提示词版本，每图写清目的理由允许变化事实锁参考图与检查要求，同输入稳定。
产出 编译器与版本。
验收 无事实支持图型不入计划，失败不回空提示词。
T6 D3.R4 提示词版本控制，依赖 T5
目标 高级用户可看可改可回。
输入 T5版本。
处理 展示差分派生撤销恢复推荐与影响预览。
产出 编辑器。
验收 编辑必生新版，只 stale 真实依赖图。
失败 故障保留最后提交版。
T7 D3.R5 伪 provider 恢复证明，依赖 T6
目标 覆盖异常与重启。
输入 T6状态。
处理 跑正常拒绝失败未知重复提交响应丢失与重启轨迹，同动作不重复提交。
产出 轨迹与探针。
验收 任一重复隐选恢复丢失即阻断门三。
T8 D4.1 正式执行每图，依赖门三
目标 真实调用入状态机。
输入 冻结计划与预算许可。
处理 每次过权限预算重复门，经适配器提交，下载后才算成，候选原图不覆盖。
产出 执行器与写入。
验收 失败未知留本图，不动旧候选。
T9 D4.2 事实验证路由，依赖 T8
目标 逐事实给责任证据。
输入 候选与验证注册表。
处理 跑技术规则平台规则与逐事实路由，每项展示责任者版本值证据与过改未知，模型建议与硬门可区分。
产出 验证结果。
验收 未决硬事实不可选，不稳转人工，不假绿。
T10 D4.3 审核选择，依赖 T9
目标 人工定夺。
输入 T9结果。
处理 多候选对比，给留重做拒收理由，生成不自动选中。
产出 评审选择接口与界面。
验收 冲突须刷新，不后写盖前写。
T11 D4.4 返工定向变化，依赖 T10
目标 原因变动作。
输入 原因表与影响分析。
处理 技术形态走确定性处理，场景走图与提示词，身份走参考图或路线，精确文字走版式层，未知走人工，旧候选保留。
产出 新尝试或修复版本。
验收 原因不明不重跑，失真不堆否定词。
T12 D4.5 单图隔离证明，依赖 T11
目标 证隔离成立。
输入 前后快照账本哈希差。
处理 比对目标图新候选与未动图不变性。
产出 隔离证据。
验收 未动图提交为零，失败回滚。
T13 D5 体验导出，依赖门四
目标 陌生人可用与交付可验。
输入 走查定页与新状态。
处理 首页讲清虚构边界百炼调用与步骤，工作台只渲染后端权威，缺料失败未知拒绝各有去处，精确文字确定性合成，最终文件重检后出不可变交付包。
产出 工作台合成器导出包与说明诊断。
验收 刷新重启一致，读不到显未知，导出只含已选复检通过版，哈希免责一致。
T14 D6 最终真人验收，依赖门五
目标 新真人走通最终版。
输入 终版与说明。
处理 开发者先跑代理轨迹清阻塞，再查键盘可读性，最后换新人走默认生成一次返工与导出。
产出 记录与问题回归。
验收 介入为零，改关键路径换人重验，代理不替代。
T15 D7 工程收尾，依赖门六
目标 全绿。
输入 全量检查。
处理 跑回归守卫恢复探针与端到端报告。
产出 报告。
验收 任一不过不宣布完成。
