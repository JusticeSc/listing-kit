## 3. 一次真实会话能补齐什么（方案 A）

- 一场「新建 → 真实整套生成 → 一次真实单图返工 → 人工选择 → 导出」即可同时补齐 C6/C8/C9/C10/C11 的最终版本真实证据与 C12 的陌生人证据。
- 预算：1 个整套批次（动态方案，通常 3–5 张）+ 1 张返工，约 4–6 次图片生成；语义文本调用少量；Unknown 只按原 task id 核对，不重复提交。
